# Ascend — система прокачки через калистенику (Python + Flet)

## 1. Запуск на компьютере

```
python -m venv .venv
.venv\Scripts\activate          (Windows)
source .venv/bin/activate       (macOS/Linux)
pip install -r requirements.txt
flet run src/main.py
```

Откроется окно приложения. Данные сохраняются в `src/storage/ascend.json`.

## 2. Сборка APK для телефона

Из папки проекта:

```
flet build apk
```

При первой сборке Flet сам скачает Flutter, JDK и Android SDK (несколько ГБ, займёт время).
Готовый файл: `build/apk/app-release.apk` — перекинь на телефон и установи
(разреши установку из неизвестных источников).

## Механика

- Анкета: имя, вес, рост, опыт, инвентарь. Все начинают с ранга E.
- Ежедневный квест: на ранге E — только отжимания и подтягивания,
  с ранга D добавляются ноги и кор (настраивается в `QUEST_UNLOCK` в `game.py`).
  Подходов: 3 на рангах E–D, 4 на C–B, 5 на A–S.
- День идёт в три этапа: Разминка → Квест → Заминка.
  Разминка (~4 мин: подвижность, растяжка, кор) обязательна — без неё квест не принять.
  Заминка (~4 мин растяжки) открывается после квеста, её можно пропустить; без пропусков даёт +15 XP.
  Оба списка — `WARMUP` и `COOLDOWN` в `game.py`.
- Квест сначала приходит окном Системы с минимальной нормой на подход — его нужно принять.
  После каждого подхода вводишь регулятором (−/+ и ползунок), сколько сделал на самом деле.
  Для статики таймер ставится тем же регулятором, кнопка «Сдался» записывает фактическое время.
- Прогрессии упражнений взяты из Recommended Routine (r/bodyweightfitness) и Convict Conditioning,
  у каждого упражнения есть подсказка по технике. Норма на новой ступени — около 40% от цели.
- Закрыл все подходы на норму — завтра норма +1 повтор (или +5 с).
  Дошёл до цели ступени — открывается следующее упражнение.
- XP за подходы + 50 XP за весь квест. Ранги: E (1–10), D (11–20), C (21–30), B (31–40), A (41–50), S (51+).
- Программы навыков (вкладка «Программы»): выход силой, горизонт, передний вис, стойка на руках, задний вис.
  4 недели × 3 тренировки, последняя — испытание. Не больше одной тренировки в день, перед ней — разминка.
  +40 XP за тренировку, +300 XP и навык в профиль за всю программу. Одновременно — одна программа.
- Ежедневный замер веса: при первом открытии за день Система спрашивает вес (можно пропустить).
  Во вкладке «Статус» — текущий вес, изменение за неделю, график и последние замеры.
- Пропуск дня: −30 XP (максимум за 3 дня), серия обнуляется, уровень не падает.
- Таймер отдыха 60 с и таймер удержания для статики, с вибрацией.

## Файлы

- `src/game.py` — упражнения, уровни, ранги
- `src/programs.py` — месячные программы навыков: недели, упражнения, испытание
- `src/guides.py` — подробная техника упражнений: мышцы, шаги, ошибки, как облегчить/усложнить
- `src/engine.py` — квест, прогрессия, штрафы, сохранение
- `src/ui.py` — палитра и компоненты дизайна (карточки, кольца, кнопки)
- `src/main.py` — точка входа
- `src/app.py` — каркас: состояние, рендер вкладок, тикер таймеров, очередь событий
- `src/anim.py` — анимации (появление, пульсация, упругие эффекты)
- `src/dialogs.py` — окна событий Системы и «Как выполнять»
- `src/common.py` — общие константы и форматирование
- `src/screens/` — экраны: `onboarding`, `status`, `quest`, `routine` (разминка/заминка), `programs`, `skills`, `history`

Экраны — миксины: `AscendApp` в `app.py` собирается из классов `screens/*`, `anim.py` и `dialogs.py`.
